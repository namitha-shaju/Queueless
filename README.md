About the Project

Queueless is a web-based hospital queue management system designed to simplify the process of booking tokens and managing patient queues.

The project provides an interface where patients can select hospital departments, generate queue tokens, view their waiting status, and manage their profile. It also includes an administrative dashboard for monitoring queues and viewing reports.

The website is developed using HTML, CSS, and JavaScript, with a responsive interface designed for both desktop and mobile devices.

Features

Patient Portal

- Patient login and registration interface
- Personalized patient dashboard
- Department-based token generation
- Queue position and waiting status
- Token details and printable receipts
- Patient profile and token history

Admin Dashboard

- Queue monitoring and management
- Department-wise queue information
- Patient activity overview
- Token status management
- Queue performance reports

Reports & Analytics

- Daily token volume
- Average waiting time
- Average service time
- Peak hours
- Completed and skipped tokens

Website Interface

- Responsive navigation
- Hospital department listings
- FAQ section
- Contact section
- Burgundy-themed interface with a clean, structured layout

Getting Started

1. Clone the repository:
   
   "git clone https://github.com/namitha-shaju/Queueless.git"

2. Open the project folder.

3. Run "index.html" in a web browser.

4. Explore the patient portal, queue management features, and admin interface.

Keep all three source files in the same directory to ensure the styling and JavaScript load correctly.

How It Works

1. Login: Access the patient portal through the login interface.
2. Select Department: Choose the required hospital department.
3. Generate Token: Receive a department-specific token number, such as "cardio-005".
4. Track Queue: View queue information through the patient dashboard.
5. Manage Profile: Access patient details and token history.
6. Admin Management: Monitor queue activity and view reports.

Project Status

Front-end development

The current version focuses on interface design, navigation, and browser-based queue management functionality.

The application does not currently use a backend server or centralized database. Authentication and queue information are handled locally for prototype purposes.
